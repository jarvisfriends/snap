# Security Policy

## Supported versions

Only the latest tagged release and the current `main` branch receive security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository rather than opening a public issue.
You should receive an initial response within a week.

Snap is intended to stay local-first and dependency-light. If you find code
that violates that assumption or introduces a risky terminal or supply-chain
behavior, report it the same way.
